# Privacy Policy for Amazon Ads MCP Local Agent

Effective date: May 26, 2026

## Overview

Amazon Ads MCP Local Agent is a local/private tool used by the authorized Amazon Ads account owner to connect AI assistant workflows with the Amazon Ads API through Amazon's official MCP server.

This tool is intended for advertising account analysis, reporting, campaign management, and related account-owner workflows.

## Data We Access

When authorized by the Amazon account owner, the tool may access Amazon Ads data that is available through the Amazon Ads API/MCP server, such as:

- Advertising account identifiers and profile information
- Campaign, ad group, ad, keyword, targeting, budget, and bid information
- Advertising performance metrics and reports
- Billing, invoice, or account metadata when available through authorized Amazon Ads API scopes

## How We Use Data

Authorized data is used only to provide local advertising analysis, reporting, optimization, and account management functions requested by the account owner.

We do not sell Amazon Ads data. We do not use Amazon Ads data for third-party advertising. We do not share Amazon Ads data with third parties except when required to provide the requested service, comply with applicable law, or follow Amazon's API requirements.

## Data Storage

This local agent does not intentionally publish Amazon Ads account data. Any credentials, tokens, or API responses should be stored only in the account owner's local environment or systems controlled by the account owner.

The operator is responsible for securing local environment variables, access tokens, refresh tokens, logs, and exported reports.

## Data Retention

Data is retained only as needed by the account owner for local workflows, troubleshooting, reporting, or compliance. The account owner may delete local files, logs, and credentials at any time.

## User Control

The Amazon account owner can revoke authorization or rotate credentials through Amazon Developer, Login with Amazon, Amazon Ads API authorization flows, or related Amazon account settings.

## Security

Reasonable safeguards should be used to protect credentials and advertising data, including environment variables, local file permissions, and avoiding public disclosure of access tokens or API responses.

## Contact

For questions about this local/private tool, contact the operator of the Amazon Developer security profile that links to this policy.
